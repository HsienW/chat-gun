# 範圍與限制

這個版本展示的是 runtime 的治理能力 — 統一的工具調度、可持久化的人工核准、邏輯冪等、副作用紀錄、帶出處的檢索與可重跑的評測。這些機制是真實的；用來展示它們的業務情境是模擬的。

- **語料為合成資料。** 知識庫中的商品與政策文件全部為合成內容，檔頭標記為合成，不含個資，不代表任何真實商品或營運規則。
- **訂單工具為模擬。** 退款與取消操作作用在模擬訂單系統上，不存在任何真實交易、付款或外部供應商整合。
- **工具在行程內執行。** 作業系統層級的隔離沙箱已有設計與契約，但尚未隨此版本出貨。宣告為獨立行程執行的工具會在註冊或調度階段被明確拒絕，不會退回到行程內執行。
- **不提供還原操作。** 可以在副作用發生前取消；已發生的副作用沒有補償流程，因此不提供還原介面。
- **沒有使用者可見的操作歷史投影。** 單筆操作的狀態可查詢，但沒有跨操作的歷史列表頁。
- **「結果未知」只到建立對帳任務。** 自動對帳的背景處理尚未實作。
- **模型選擇為固定設定。** 沒有依能力註冊表自動選模的機制。
- **評測為離線回歸。** 沒有影子流量、灰度或 A／B 比較機制。
- **數字的意義。** 所有公布的數字都記錄資料集版本、模型識別、prompt 版本、執行次數與日期，代表方法在受控合成資料集上的有效性，不代表正式環境表現。無法由記錄的版本重現的數字會被撤下，而不是加註。

訂單資料同樣為合成資料；此版本不提供 undo。流程評測中的 live 訂單操作限制見[完整評測](./evaluation.md#流程評測)。
